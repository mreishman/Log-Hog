# Settings and jQuery security update

## Security

- Updated bundled jQuery from 1.12.4 to 3.8.0, which includes upstream fixes for cross-site scripting in DOM manipulation methods.
- Save validated profile settings, global settings, custom theme defaults, and configuration backups as JSON.
- Block direct web access to configuration files, layout data, and custom theme defaults in the bundled Docker deployment.

## Upgrading

- Back up the Log-Hog data volumes before upgrading. Log-Hog converts legacy PHP settings and layout files to JSON on first use without executing them. It keeps the original files and uses the JSON copies on subsequent requests.
- If a hand-edited legacy file contains PHP expressions or function calls, restore a trusted backup or convert the settings to JSON manually.

## Compatibility

- Updated the log group selector to work with jQuery 3.
- Fixed the global settings version check so upgrades can confirm that migration succeeded.
- Fixed custom theme creation so new themes receive their stylesheets and icons.
