# PHP and Docker maintenance

- Upgraded to PHP 8.6.0 and standardized Docker and Compose on the official PHP Apache image.
- Docker Compose keeps settings, profiles, custom themes, and log history in named volumes so they survive container replacement.
- Removed in-app update checks, installation, and rollback. Upgrade Docker installations by rebuilding and recreating the container with the same data volumes. Configuration, layout, and theme migrations still run as needed.
- Updated the README with Docker Desktop and Compose setup, multiple log mounts, backup and migration steps, and screenshots with sample logs.
- Added automated tests for all 256 saved module combinations and browser workflows including live logs, background polling, unsaved changes, and theme switching.
